# Pet Shop REST API

REST API интернет-магазина зоотоваров на Go с использованием реляционной СУБД PostgreSQL. Проект демонстрирует написание SQL-запросов, работу со сложными связями (JOIN), транзакции и аналитику.

---

##  Архитектура и структура проекта

Проект построен по принципам чистой слоистой архитектуры:

- `cmd/`
  - `app/main.go` — точка входа сервиса (инициализация конфигурации, БД, логгера, роутера и запуск сервера).
  - `migrator/main.go` — утилита применения SQL-миграций (`golang-migrate`).
- `config/local.yaml` — локальные параметры конфигурации сервиса.
- `internal/`
  - `config/` — парсинг и валидация конфигурации.
  - `handlers/` — транспортный слой HTTP (роуты, валидация DTO, сериализация JSON).
  - `storage/` — слой данных: интерфейсы и реализация репозиториев для PostgreSQL.
  - `lib/` — внутренние вспомогательные утилиты (структурированный логгер `slog`).
  - `models/` — доменные структуры и модели базы данных.
- `migrations/` — файлы SQL-миграций схемы данных (`up` / `down`).
- `Taskfile.yaml` — автоматизация запуска миграций и линтера.

## План реализации по веткам

Каждая версия проекта дополняет предыдущую и разрабатывается в отдельной ветке:

- **`main`** — каркас проекта: инициализация компонентов, конфигурация, подключение к БД и health-check.
- **`v1` — Товары и пользователи:**
  - Базовые CRUD-операции для таблиц `users` и `products` (простые `SELECT` и `INSERT`).
  - Эндпоинты управления товарами и клиентами.
- **`v2` — Заказы и позиции:**
  - Сущности `orders` и `order_items`.
  - Создание заказов, добавление позиций, выборка информации с использованием `JOIN`.
- **`v3` — Оформление заказа в транзакции:**
  - Реализация метода `PlaceOrder` в единой атомарной транзакции (`tx`).
  - Проверка и списание остатков на складе (`stock`), создание заказа, позиций и записи в `transactions` с `Commit` / `Rollback`.
  - Эндпоинт `POST /checkout`.
- **`v4` — История транзакций и аналитика:**
  - Полная сводка заказов и платежей пользователя через связанные `JOIN`.
  - SQL-агрегация (`GROUP BY`) для эндпоинта популярных товаров `GET /products/popular`.
