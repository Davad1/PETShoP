## V1 — Пользователи и продукты

В этой версии реализована работа с пользователями и добавлено получение продукта по ID.

### Пользователи

- Создание пользователя с именем и email.
- Получение пользователя по email.
- Получение списка всех пользователей.
- Проверка обязательных полей при создании.
- Проверка формата email при поиске.

### Продукты

Сохранены существующие операции создания, обновления, удаления и получения списка продуктов. Добавлен метод получения одного продукта по ID.

### Реализация

- HTTP-обработчики на net/http и chi.
- Хранение данных в PostgreSQL с использованием pgx.
- Передача context из HTTP-запроса в методы хранилища.
- Логирование через slog.
- Модульные тесты обработчиков с ручными моками хранилища.

### Запуск проекта

1. Создать `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```

2. Запустить контейнеры с базой данных:
   ```bash
   docker compose up --build
   ```

3. Линтер:
    ```bash
    golangci-lint run ./... 
    ```

### Запуск тестов

Из корневой папки проекта:
    ```bash
    go test -v ./...
    ```
